# Smart Dustbin Using ESP32

An ESP32-based automated dustbin with touch-free lid operation and waste-level monitoring.

## Features
- Hand detection using HC-SR04
- Automatic lid control using servo motor
- Waste-level monitoring
- 80% full alert using buzzer and LED
- 16x2 I2C LCD display

## Hardware
- ESP32
- 2 × HC-SR04 Ultrasonic Sensors
- Servo Motor
- 16x2 I2C LCD
- Buzzer
- LED

## Software
- Arduino IDE
- Arduino C++
- ESP32 Board Package
